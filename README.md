## 📌 Featured projects

### [RelayKit](https://github.com/Yermukhambet-raiymbek/relaykit) — durable webhook delivery service
`Go` `SQLite` `Docker` · portfolio MVP

Accepts an event once, records every delivery attempt, retries transient failures and replays dead letters without losing history.
- Idempotency keys, atomic claims with expiring leases and fencing tokens
- Exponential backoff, `Retry-After`, HMAC-SHA256 signatures, SSRF-safe destination policy
- Deterministic integration tests with a fake clock; concurrency tests under the race detector

### [EvidenceDesk](https://github.com/Yermukhambet-raiymbek/evidence-desk) — auditable document Q&A backend
`TypeScript` `Node.js` `SQLite` `BM25` · portfolio MVP

Every returned excerpt points to an immutable document revision and exact line range; refuses to answer when there is no evidence. Optional local LLM (Ollama) evidence selector.

### [LittleVillage](https://github.com/Yermukhambet-raiymbek/HalalOrta) — family baby-care learning app · [live](https://halalorta.onrender.com)
`Go` `PostgreSQL` `React` `TypeScript`

Families take short lessons with server-graded quizzes, share care tasks and a weekly schedule; a task shows whether the assignee has passed the lesson it requires.

### GlobalToProject — B2B equipment catalogue & quotation platform
